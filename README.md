# 试卷专项检查报告助手

面向大数据与人工智能学院任课教师的试卷检查 skill。教师提供姓名、确认课程、上传归档材料后，助手会对照学院归档目录逐项清点材料、核算成绩、核查命题形式与“两性一度”，最终生成不少于 1000 字的《教师试卷检查结果报告》Word 文档和《试卷自查登记表》。**不判断题目与答案的对错**，整改建议面向下一套试卷或下一轮教学，不要求改动本次归档材料。

## 项目背景

学院开展近两年试卷专项检查，任课教师需在 **2026 年 11 月 4 日前**完成课程试卷自查，向所属系主任提交检查报告和自查登记表。实际撰写时，教师通常要反复翻查：

- 四个学期的《课程归属表》，确认课程性质、班级、人数、考核方式；
- 三个学期的《试卷归档清单》，确认是否归档、归档编号和存放位置；
- 纸质版或机考版《本科课程考试试卷档案归档目录》，逐项核对 9 类材料；
- 成绩单，手工计算平均分、及格率、优秀率、标准差和分数段；
- 试题结构，判断 A/B 卷是否齐全、题型分值是否合理、高阶题集中在哪些题目，不需要逐题验算答案。

这些工作重复、容易漏项，报告还要求数据准确、方向明确、措施对应。本项目把上述流程固化为一个可被 AI Agent 调用的 skill，用脚本完成查询、清点和统计，用固定模板生成文档，教师只需确认课程、确认整改方向。

## 功能概览

| 能力 | 说明 |
| --- | --- |
| 课程查询 | 按教师姓名检索课程归属与归档信息，输出课程卡片供教师确认 |
| 材料清点 | 按纸质版/机考版归档目录逐项核对，列出缺失项、空文件、人数异常和未识别文件 |
| 深度核查 | 提取试题、答案、分析表文本；统计成绩；逐题登记认知层次与分值（占比只进核查底稿）；只看题目结构，不验算答案 |
| 整改点选择 | 从通用整改点库（P1—P8）中按课程实际选 3—5 条，写成下一套卷或下一轮教学可改进的方向；答案对错、材料缺件、系统口径、签章只在对话里提醒 |
| 报告生成 | 按学院模板排版，五模块齐全，正文不少于 1000 字，数字与底稿一致 |
| 登记表生成 | 把确认后的通用整改点写入《试卷自查登记表》，横向单页打印 |

整个流程在课程确认和整改方向确认两个关键节点停下来等教师答复，教师未确认前不会继续下一步，也不会编造缺失数据。

## 样例目录

`试卷材料/` 和 `输出_试卷检查报告/` 是两套完整示例，用来回答两个问题：**要交哪些文件、每个文件长什么样**，以及**最终报告和登记表长什么样**。其中的教师、课程、班级、学生信息已全部替换为占位符，其余内容（材料种类、表格版式、成绩数据、整改方向）保持真实运行结果，可直接对照。

占位符约定：

| 占位符 | 含义 |
| --- | --- |
| `【教师姓名】` | 任课教师、出卷教师、课程负责人 |
| `【课程名称】` | 课程名称（如试卷标题、成绩单表头） |
| `【课程代码】` | 教务系统课程号 |
| `【班级名称1】`、`【班级名称2】` | 授课班级（含校区前缀的写法也已替换） |
| `【学生姓名】`、`【学号】` | 成绩单、平时成绩登记表、成绩分析表中的学生信息 |
| `【所属系部】` | 教师所属教研室 |
| `【归档编号】`、`【档案室】` | 课程归档编号与纸质材料存放位置 |
| `【先修课程名称】` | 报告中提及的先修课程 |

`试卷材料/` 下每个示例目录的用途：

| 子目录 | 内容 |
| --- | --- |
| `原件/` | 教师收到的原始文件，保留 `.doc`/`.xls` 等旧格式 |
| `材料/` | 按归档目录整理后的材料；新版示例同时保留旧格式文件 |
| `转换/` | 为文本提取而转换出的 `.docx`/`.xlsx`，以及成绩记录 `recs.json` |
| `txt/` | 从材料中提取的纯文本，便于逐题核查 |

`输出_试卷检查报告/` 下每个示例目录包含（`_新版` 为最新样例，旧目录保留用于对比）：

| 文件 | 说明 |
| --- | --- |
| `【教师姓名】_【课程名称】_试卷检查结果报告.docx` | 正式报告，`_新版` 约 2450 字、5 页，教师签名与日期留空 |
| `【教师姓名】_【课程名称】_试卷自查登记表.xlsx` | `_新版` 为 4 条通用整改方向，A4 横向单页 |
| `核查底稿.md` | 成绩统计、逐题登记、整改点选择与提醒事项的过程记录 |
| `report_payload.json`、`issues.json` | 报告与登记表的结构化数据 |
| `预览/` | 新版示例的报告逐页 PNG 与两份 PDF，便于直接翻阅 |

学校统一印制、教务系统导出、需要纸质签章的表格保留原有版式，只替换姓名、课程、班级、学号等字段；人数、成绩、比例等数字保留，用于演示统计口径和报告写法。

## 使用流程

### 第 1 步：提供基本信息

告诉助手三件事：

1. 姓名（须与《课程归属表》一致）；
2. 本次检查哪门课、哪个学期（同一学期有多门课时）；
3. 材料是否已准备好。

课程性质、班级、人数、考核方式、归档编号不需要教师提供，助手会从内置知识库查询。

### 第 2 步：确认课程

助手查询后展示课程卡片，包括课程名称与编号、课程性质、学期、考核方式、班级人数、教研室与系主任、材料存放位置与归档编号、适用清单。教师回复“是这门课”后才进入材料环节。

如果查不到，助手会请教师核对姓名写法，或补充“课程名称 + 学期 + 班级”，不会凭空补课程信息。

### 第 3 步：准备并上传材料

把材料放到以下目录（支持按班级建子文件夹，也可直接在对话中上传）：

```
试卷材料/<教师姓名>_<课程名称>_<学期>/
```

助手先给出本次应提交的清单，再运行清点脚本。结果分三部分反馈：已收到什么、还缺什么、哪些文件未能识别。已收到的材料先做核查；缺件只在交付对话中提醒，并记为“未提供、本项未能核验”，不写进报告第四部分。

### 第 4 步：确认整改方向

材料清点后，助手逐项核查并汇报：已核验的数据、拟写进报告的 3—5 条通用整改方向（带一句事实依据）、只在对话里说明的提醒事项、无法核验的项目。教师确认整改方向合适后，才进入文档生成。

### 第 5 步：获取交付文件

生成目录如下：

```
输出_试卷检查报告/<教师>_<课程>_<学期>/
├── <教师>_<课程>_试卷检查结果报告.docx
├── <教师>_<课程>_试卷自查登记表.xlsx
├── 核查底稿.md
├── report_payload.json
└── issues.json
```

报告已按学院模板排版，正文不少于 1000 字，包含课程信息表、五个模块和成绩统计表。**教师签名和日期留空，需本人手写。**

## 需要提供哪些材料

材料要求取决于考核方式。助手查询课程后会自动选择对应清单。

### 笔试类课程（纸质版，9 项）

| 序号 | 材料 | 要求 |
| --- | --- | --- |
| 1 | 期末考试试题 | A4 版本原稿，A/B 卷一套 |
| 2 | 标准答案及评分标准 | 与试题配套，给分点明确 |
| 3 | 学生成绩单 | 教务系统导出，含考试简况/实到人数 |
| 4 | 学生平时成绩登记表 | 2025 年教务处制，注明分数来源 |
| 5 | 班级成绩分析表 | 系统导出，数据以系统为准；只核表内算术与跨班雷同 |
| 6 | 课程试卷及成绩分析表（试卷类） | 系统导出，格式固定；电子检查阶段只清点是否收到 |
| 7 | 期末考试专用答题册 | 纸质归档，按学号由小到大排列；电子材料未附不算缺失 |
| 8 | 试卷审核表（复印件） | 纸质版签字盖章完整；电子稿无签章属正常；打印份数等纸面项作提醒 |
| 9 | 其他材料 | 如《归档材料补充说明》、缓考/补考材料 |

### 机考 / 考查类课程（电子版，9 项）

| 序号 | 材料 | 要求 |
| --- | --- | --- |
| 1 | 期末考试试题 | 电子版 |
| 2 | 标准答案及评分标准 | 电子版，与机考评分规则一致 |
| 3 | 学生成绩单 | 电子签章，或打印签字盖章后扫描 |
| 4 | 学生平时成绩登记表 | 打印盖学院公章再扫描/拍照 |
| 5 | 班级成绩分析表 | 数据以系统导出为准；只核表内算术与跨班雷同 |
| 6 | 课程试卷及成绩分析表 / 课程考核成绩分析表 | 按考试类型二选一；试卷类系统导出、格式不作要求，非试卷类由教师自填；每班一份复核说明 |
| 7 | 期末考试专用答题册 | 系统导出，每位学生一份，可按学号定位 |
| 8 | 试卷审核表 | 打印盖学院公章后扫描/拍照 |
| 9 | 其他材料 | 复核说明、补充说明等 |

### 文件格式与命名

支持 `.docx`、`.doc`、`.xlsx`、`.xls`、`.pdf`、图片和压缩包。建议文件名直接体现材料类型，例如：

```
Java程序设计A卷.docx
标准答案及评分标准.docx
学生成绩单.xlsx
学生平时成绩登记表.docx
课程试卷及成绩分析表.docx
答题册/答题册_20250001.pdf
```

文件名只用于初步归类，助手仍会打开原件核对内容；扫描件请保证文字可辨认。

## 内置知识库

`references/kb/` 已内置：

- 2024-2025-1、2024-2025-2、2025-2026-1、2025-2026-2 四个学期《课程归属表》；
- 2024-2025-2、2025-2026-1、2025-2026-2 三个学期《清远校区试卷归档清单》；
- 《试卷互查记录表》《试卷自查登记表》模板。

知识库是快照。学期超出上述范围，或教师、课程查不到时，请把最新表格放入 `references/kb/` 后重跑，助手不会猜测课程信息。

## 核查口径

- **成绩统计**：平均分、标准差（总体）、最高/最低分、及格率（≥60）、优秀率（≥90）、不及格率、五档分数段；缺考、缓考、作弊等非数值记录单列，不计入均值。
- **成绩异常**：不及格率或优秀率 ≥30% 且 <40%，由教研室写成绩异常分析报告；≥40%，由二级教学单位写课程考核整改意见。
- **“两性一度”**：按 Bloom 认知层次逐题登记识记、理解应用、分析综合及分值，逐题表与占比只放核查底稿；报告正文用题号、分值、题干要求说明高阶性、创新性、挑战度，不写百分比。没有试题原文时不做逐题判断，也不虚构阈值。
- **材料一致性**：成绩单与平时成绩表人数核对；答题册只在教师主动提供时核对份数与顺序。系统导出表的均值、标准差、及格率、优秀率口径不作为问题。
- **命题形式**：只看 A/B 卷是否齐全、题型题量与分值结构是否一致、卷面要素是否完整、评分标准是否按题给出给分点。**不验算题目、不比对答案数值、不判断选项唯一性、不判断答案与试题知识范围是否对应**；疑似答案问题只在对话中请教师复核。
- **整改点边界**：报告第四部分和登记表只放 3—5 条通用方向，依据是题型分值、评分标准结构、成绩统计或班级对比；用“还可进一步”“有待完善”表述，措施落在下一套 A/B 卷或下一教学周期。答案对错、本次材料缺件、系统导出表、统一模板字段、表内算术、纸质签章与答题册一律只在交付对话中提醒。规程见 `references/issue-library.md` 与 `references/issue-triage.md`。

## 重要说明

1. **不编造数据**。报告中的数字只来自成绩单、归档材料、知识库或教师明确确认；无法核验的项目会写成“未提供、未能核验”。
2. **不替教师签字**，也不写“检查合格/通过”等结论性承诺。
3. **课程和整改方向都要教师确认**。助手只负责核查与起草，最终内容由教师负责。
4. **保护学生信息**。登记表优先写学号，非必要不写姓名。
5. **扫描件需可读**。签名、盖章、学号排序等无法自动识别的项目，作为纸质归档提醒在交付时说明，不写进报告。公式、矩阵、复选框必须看渲染图，文本抽取结果不作数。
6. **不判断答案对错**。助手不承担命题与答案的学科复核，报告与登记表不出现“答案错误”“算错”“无解”等结论；教师对题目和答案的疑问，请自行或由教研室复核。

## 常见问题

**查不到我的课程怎么办？**
先核对姓名用字；再让助手用课程关键字重试。仍找不到时，提供“课程名称 + 学期 + 班级”，或更新 `references/kb/` 中的课程归属表。

**同一门课有多个学期记录，用哪个？**
助手会列出所有记录，由教师指定本次检查的学期；不同学期分别生成报告，不混在一份里。

**归档编号查不到或教师姓名对不上？**
助手会提示“需人工核对”，不会强行采用。以《试卷归档清单》原件和学院记录为准。

**成绩单识别不到列怎么办？**
助手会打印识别到的表头，可指定总评列关键字后重跑；仍失败则查看原件后手工记录，并在核查底稿中注明。

**材料确实无法补齐怎么办？**
教师明确说明后，助手把该项记为“未提供、本项未能核验”，在交付对话中说明，不写入报告第四部分，也不影响其余内容的生成。

**报告字数不够 1000 字怎么办？**
生成脚本会拦截并提示。应补充题型结构分析、成绩数据对比和可执行的改进方向，不要用空话凑字数。
