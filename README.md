# 试卷专项检查报告助手

面向大数据与人工智能学院任课教师的试卷检查 skill。教师提供姓名、确认课程、上传归档材料后，助手会对照学院归档目录逐项清点材料、核算成绩、核查命题规范与“两性一度”，最终生成不少于 1000 字的《教师试卷检查结果报告》Word 文档和《试卷自查登记表》。

## 项目背景

学院开展近两年试卷专项检查，任课教师需在 **2026 年 11 月 4 日前**完成课程试卷自查，向所属系主任提交检查报告和自查登记表。实际撰写时，教师通常要反复翻查：

- 四个学期的《课程归属表》，确认课程性质、班级、人数、考核方式；
- 三个学期的《试卷归档清单》，确认是否归档、归档编号和存放位置；
- 纸质版或机考版《本科课程考试试卷档案归档目录》，逐项核对 9 类材料；
- 成绩单，手工计算平均分、及格率、优秀率、标准差和分数段；
- 试题与答案，判断 A/B 卷是否齐全、题型分值是否合理、高阶题占比多少。

这些工作重复、容易漏项，报告还要求数据准确、问题具体、整改对应。本项目把上述流程固化为一个可被 AI Agent 调用的 skill，用脚本完成查询、清点和统计，用固定模板生成文档，教师只需确认课程、补齐材料、确认发现。

## 功能概览

| 能力 | 说明 |
| --- | --- |
| 课程查询 | 按教师姓名检索课程归属与归档信息，输出课程卡片供教师确认 |
| 材料清点 | 按纸质版/机考版归档目录逐项核对，列出缺失项、空文件、人数异常和未识别文件 |
| 深度核查 | 提取试题、答案、分析表文本；统计成绩；逐题登记认知层次并计算占比 |
| 报告生成 | 按学院模板排版，五模块齐全，正文不少于 1000 字，数字与底稿一致 |
| 登记表生成 | 把确认后的问题写入《试卷自查登记表》，横向单页打印 |

整个流程在课程确认、材料补齐、核查发现三个关键节点都会停下来等教师答复，教师未确认前不会继续下一步，也不会编造缺失数据。

## 环境要求

- Python 3.9 及以上。
- 必装：`python-docx`、`openpyxl`。
- 可选：`pypdf`（提取 PDF 文本）。扫描件无法提取文字时，由 Agent 直接查看图片核对。

```bash
python -c "import docx, openpyxl; print('ok')"
python -m pip install python-docx openpyxl
# 可选
python -m pip install pypdf
```

## 使用流程

### 第 1 步：提供基本信息

告诉助手三件事：

1. 姓名（须与《课程归属表》一致）；
2. 本次检查哪门课、哪个学期（同一学期有多门课时）；
3. 材料是否已准备好。

课程性质、班级、人数、考核方式、归档编号不需要教师提供，助手会从内置知识库查询。

### 第 2 步：确认课程

助手查询后展示课程卡片，包括课程名称与编号、课程性质、学期、考核方式、班级人数、教研室与系主任、材料存放位置与归档编号、适用清单。教师回复“是这门课”后才进入材料环节。

如果查不到，助手会请教师核对姓名写法，或补充“课程名称 + 学期 + 班级”，不会凭空补课程信息。

### 第 3 步：准备并上传材料

把材料放到以下目录（支持按班级建子文件夹，也可直接在对话中上传）：

```
试卷材料/<教师姓名>_<课程名称>_<学期>/
```

助手先给出本次应提交的清单，再运行清点脚本。结果分三部分反馈：已收到什么、还缺什么、哪些文件未能识别。**只要必需材料缺失或为空文件，助手会暂停写报告，先引导补传。**

### 第 4 步：确认核查发现

材料齐全后，助手逐项核查并汇报：已核验的数据、发现的问题（带材料位置和证据）、无法核验的项目。教师确认问题属实后，才进入文档生成。

### 第 5 步：获取交付文件

生成目录如下：

```
输出_试卷检查报告/<教师>_<课程>_<学期>/
├── <教师>_<课程>_试卷检查结果报告.docx
├── <教师>_<课程>_试卷自查登记表.xlsx
├── 核查底稿.md
├── report_payload.json
└── issues.json
```

报告已按学院模板排版，正文不少于 1000 字，包含课程信息表、五个模块和成绩统计表。**教师签名和日期留空，需本人手写。**

## 需要提供哪些材料

材料要求取决于考核方式。助手查询课程后会自动选择对应清单。

### 笔试类课程（纸质版，9 项）

| 序号 | 材料 | 要求 |
| --- | --- | --- |
| 1 | 期末考试试题 | A4 版本原稿，A/B 卷一套 |
| 2 | 标准答案及评分标准 | 与试题配套，给分点明确 |
| 3 | 学生成绩单 | 教务系统导出，含考试简况/实到人数 |
| 4 | 学生平时成绩登记表 | 2025 年教务处制，注明分数来源 |
| 5 | 班级成绩分析表 | 按班级填写，数据与成绩单一致 |
| 6 | 课程试卷及成绩分析表（试卷类） | 四段各约 200 字 |
| 7 | 期末考试专用答题册 | 按学号由小到大排列 |
| 8 | 试卷审核表（复印件） | 2025 年教务处制，签字盖章完整 |
| 9 | 其他材料 | 如《归档材料补充说明》、缓考/补考材料 |

### 机考 / 考查类课程（电子版，9 项）

| 序号 | 材料 | 要求 |
| --- | --- | --- |
| 1 | 期末考试试题 | 电子版 |
| 2 | 标准答案及评分标准 | 电子版，与机考评分规则一致 |
| 3 | 学生成绩单 | 电子签章，或打印签字盖章后扫描 |
| 4 | 学生平时成绩登记表 | 打印盖学院公章再扫描/拍照 |
| 5 | 班级成绩分析表 | 四段各约 200 字 |
| 6 | 课程试卷及成绩分析表 / 课程考核成绩分析表 | 按考试类型二选一；每班一份复核说明 |
| 7 | 期末考试专用答题册 | 系统导出，每位学生一份，可按学号定位 |
| 8 | 试卷审核表 | 打印盖学院公章后扫描/拍照 |
| 9 | 其他材料 | 复核说明、补充说明等 |

### 文件格式与命名

支持 `.docx`、`.doc`、`.xlsx`、`.xls`、`.pdf`、图片和压缩包。建议文件名直接体现材料类型，例如：

```
Java程序设计A卷.docx
标准答案及评分标准.docx
学生成绩单.xlsx
学生平时成绩登记表.docx
课程试卷及成绩分析表.docx
答题册/答题册_20250001.pdf
```

文件名只用于初步归类，助手仍会打开原件核对内容；扫描件请保证文字可辨认。

## 内置知识库

`references/kb/` 已内置：

- 2024-2025-1、2024-2025-2、2025-2026-1、2025-2026-2 四个学期《课程归属表》；
- 2024-2025-2、2025-2026-1、2025-2026-2 三个学期《清远校区试卷归档清单》；
- 《试卷互查记录表》《试卷自查登记表》模板。

知识库是快照。学期超出上述范围，或教师、课程查不到时，请把最新表格放入 `references/kb/` 后重跑，助手不会猜测课程信息。

## 核查口径

- **成绩统计**：平均分、标准差（总体）、最高/最低分、及格率（≥60）、优秀率（≥90）、不及格率、五档分数段；缺考、缓考、作弊等非数值记录单列，不计入均值。
- **成绩异常**：不及格率或优秀率 ≥30% 且 <40%，由教研室写成绩异常分析报告；≥40%，由二级教学单位写课程考核整改意见。
- **“两性一度”**：按 Bloom 认知层次逐题登记识记、理解、应用、分析综合，输出分值与占比，并结合题目说明高阶性、创新性、挑战度；没有试题原文时不做逐题判断，也不虚构百分比阈值。
- **材料一致性**：成绩单人数、平时成绩表人数、答题册份数三者核对；出现差异必须有《归档材料补充说明》。

## 重要说明

1. **不编造数据**。报告中的数字只来自成绩单、归档材料、知识库或教师明确确认；无法核验的项目会写成“未提供、未能核验”。
2. **不替教师签字**，也不写“检查合格/通过”等结论性承诺。
3. **课程和问题都要教师确认**。助手只负责核查与起草，最终内容由教师负责。
4. **保护学生信息**。登记表优先写学号，非必要不写姓名。
5. **扫描件需可读**。签名、盖章、学号排序等无法自动识别的项目，会作为人工核对项在报告中如实体现。

## 常见问题

**查不到我的课程怎么办？**
先核对姓名用字；再让助手用课程关键字重试。仍找不到时，提供“课程名称 + 学期 + 班级”，或更新 `references/kb/` 中的课程归属表。

**同一门课有多个学期记录，用哪个？**
助手会列出所有记录，由教师指定本次检查的学期；不同学期分别生成报告，不混在一份里。

**归档编号查不到或教师姓名对不上？**
助手会提示“需人工核对”，不会强行采用。以《试卷归档清单》原件和学院记录为准。

**成绩单识别不到列怎么办？**
助手会打印识别到的表头，可指定总评列关键字后重跑；仍失败则查看原件后手工记录，并在核查底稿中注明。

**材料确实无法补齐怎么办？**
教师明确说明后，助手把该项记为“未提供、未能核验”，写入报告第四部分，经教师确认后继续。

**报告字数不够 1000 字怎么办？**
生成脚本会拦截并提示。应补充题目证据、数据对比和具体整改措施，不要用空话凑字数。
