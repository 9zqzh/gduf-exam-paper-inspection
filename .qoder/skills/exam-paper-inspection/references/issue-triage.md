# 问题认定：写进报告前的三道筛子

试卷检查最容易犯的错，不是漏查，而是把**学校系统性事项**写成教师的“问题”：系统导出的成绩分析表、统一模板里的占位列、纸质归档才有的签字盖章、学校统一印制的卷面栏。这些内容写进报告，教师改不动，登记表也填不了，反而让真正的问题被淹没。

另一个高频错误是**把抽取工具的产物当成原件事实**：公式被抽错位、复选框被抽成空、合并单元格被拆乱，于是“发现”了并不存在的错误。

因此，任何一条发现写进报告前，先过下面三道筛子。

## 第一道：责任归属——教师能改吗？

| 责任主体 | 典型材料 | 处理 |
| --- | --- | --- |
| 教师可控 | 试题题干、参考答案、评分标准、自编卷面、平时成绩表内的计算 | 可能列为硬性问题 |
| 学校系统 | 成绩单、班级成绩分析表的数值与版式、课程级分析表模板 | 只做记录，不质疑 |
| 统一模板 | 平时成绩表的“XX”占位列、权重栏、审核表打印份数栏 | 不列 |
| 纸质归档 | 手写签名、公章、日期、答题册实体、审核表复印件、装订排序 | 对话提醒，不列 |

只有“教师可控”的事项，才可能进入报告第四部分和《试卷自查登记表》。

## 第二道：证据门槛——我看到的是原件还是抽取结果？

- **公式、矩阵、向量、上下标**：必须把页面渲染成图片逐字核对。文本抽取与答案冲突时，先怀疑抽取，不怀疑试卷。
- **复选框、勾选符号**：Word 常用符号字体，文本层经常抽成空或错字。必须看渲染图；看不到就写“未能核验”，不能写“未勾选”。
- **合并单元格、左右双栏、多班叠放的成绩表**：按学号逐行核对，并与成绩单交叉验证人数、分数段合计；不能只信一次自动统计。
- **扫描件、手写内容**：看不清就不判断，不用推测补全。
- **“数据不一致”类结论**：至少两处独立来源能对上（如成绩单与班级分析表），并写出具体数值和算式，才算证据充分。
- **“题目/答案有错”类结论**：按 `paper-correctness.md` 执行，必须两次独立复算（换一种方法也要得出同一结论）+ 回原件逐字核对 + 反方论证排除多解与约定差异。只算一遍、只凭印象、或只凭文本抽取就断言，一律不算证据。

过不了这一道，就不写进报告；确有疑点，只在对话里请教师复核。

## 第三道：影响判断——不改会怎样？

| 影响 | 判定 |
| --- | --- |
| 影响评分公平、成绩准确、材料完整、命题规范 | 硬性问题 |
| 只影响观感、风格、难度体感、可优化空间 | 提示事项（对话） |
| 教师有意为之且有合理解释 | 不列 |

## 硬性问题准入（四条同时满足）

1. **教师可控**：通过改题、改答案、改表内计算、改排版就能解决。
2. **位置明确**：材料名 + 页码/题号/单元格/学号，能直接翻到。
3. **证据可复核**：引用原文、截图或算式，换一个人也能得出同样结论。
4. **影响清楚**：一句话说清不改的后果（如“评分无依据”“总评无法复核”）。

四条缺一条，就不要写成硬性问题。

## 默认不列清单

| 类别 | 例子 | 处理 |
| --- | --- | --- |
| 学校系统导出表 | 班级成绩分析表的均值、标准差、及格率、优秀率口径；课程级分析表的固定格式 | 底稿注明“系统导出”，报告中不质疑 |
| 统一模板字段 | 平时成绩表“XX”占位、权重未印在表内、审核表打印份数 | 不列 |
| 学校统一印制卷面 | 专业班级、考试日期、答题要求栏 | 不列 |
| 纸质归档环节 | 电子稿无手写签名/公章/日期、答题册未随电子材料、审核表为复印件 | 交付时口头提醒 |
| 教师评分尺度 | “只写 1 也算对”“酌情给分”“步骤从宽” | 不列 |
| 无法预知的数量 | 补考/缓考卷打印份数留空 | 不列 |
| 单题难度体感 | 计算量大、需数值方法、两卷难度感觉不对等 | 对话提醒；但 A/B 卷题型、题量、分值结构不一致仍属硬性 |
| 模板与格式 | 封面模板、归档目录样式、系统导出表的排版 | 不列 |

## 两个出口

- **文件出口**：报告第四部分写位置、事实、影响，第五部分写对应整改；《试卷自查登记表》只放同一批硬性问题。
- **对话出口**：交付时另起一段“以下事项未写入报告，供您参考”，3—6 条，每条一句话，说清是模板、系统、纸质环节还是难度建议。
- **底稿**：保留全部观察，逐条标注“硬性 / 提示 / 不列”及理由，便于复盘，也便于教师追问时解释。

## 判定示例

| 发现 | 判定 | 理由 |
| --- | --- | --- |
| B 卷标准答案的内容属于另一门课，与 B 卷试题不匹配 | 硬性 | 教师可改；答案错配直接影响评分 |
| A 卷题干残留 LaTeX 标记、填空句末重复标点、答案首页多出符号 | 硬性 | 教师可改；卷面硬伤，可直接定位 |
| 计算题第 3—8 题和证明题只有解答、没有分步给分点 | 硬性 | 教师可改；评分标准不细化 |
| 班级分析表把 11.43÷20 写成 55.2%，且与另一班数值完全相同 | 硬性 | 表内算术可复核；跨班雷同需核对 |
| 平时成绩总评与三项分值对不上，且能点名到具体学生 | 硬性 | 教师可改；影响成绩准确 |
| 课程级《课程试卷及成绩分析表》未随电子材料提供、格式只有两段 | 不列 | 学校系统导出，格式教师改不了；在材料清点中注明即可 |
| 答题册未随电子材料提供、份数与实到人数对不上 | 不列 | 纸质归档环节；教师手头通常没有电子件 |
| 班级分析表均值、标准差、及格率的口径 | 不列 | 系统导出结果，不质疑；只核表内算术与跨班雷同 |
| 成绩单、分析表、审核表的手写签字、公章、日期空白 | 不列 | 电子稿本来就没有；交付时提醒纸质版补签 |
| 审核表“考试内容涵盖教学大纲”“题目难易程度”显示未勾选 | 先复核、暂不列 | 复选框文本层不可靠；看渲染图，若已勾选则属识别错误 |
| 补考卷打印份数留空 | 不列 | 补考人数考前无法预知，留空合理 |
| 填空要求“只写 1 也算对” | 不列 | 教师有意的评分尺度，不属硬伤 |
| 卷面未预印专业班级、考试日期、答题要求 | 不列 | 学校统一印制栏，教师无法控制 |
| 某题计算量大、需数值方法，A/B 两卷难度体感有差异 | 提示 | 属命题难度建议，不写进报告；A/B 结构不一致才列为硬性 |
| 平时成绩表“XX”列未改成实际项目、未注明权重 | 不列 | 模板固定字段，教师无法修改 |
| 特征向量与答案相差非零常数倍，或正交化顺序不同 | 不列 | 多解，满足定义即正确；判错属误报 |
| SVD 的 U、V 列顺序或符号与答案不同，但 UΣVᵀ=A | 不列 | 学科约定与多解，不构成错误 |
| B 卷计算第 1 题所给矩阵不可对角化，第(3)问无解 | 硬性 | 两次复算一致：λ=1 二重、rank(A−I)=2、几何重数 1；原件核对无误，学生无法作答 |
| A 卷计算第 5 题 β3 写成 (−1,1,1)，e2 与 e3 内积 4/√18≠0 | 硬性 | 按 Schmidt 逐次投影复算应取 (1,−1,1)；内积不为 0，结果不构成标准正交基 |
| 答案只有结果、没有分步给分点 | 硬性 | 属评分标准问题，与“答案算错”分开列，不要混写 |

## 教师反驳时怎么处理

教师说“这条不对”时，先按理由归类，不要争辩，也不要因为被否定就把所有问题都删掉：

| 教师说法 | 处理 |
| --- | --- |
| “这是学校系统导出的，格式改不了” | 整条移出问题清单，在材料清点中注明“系统导出”；同类表格以后不再质疑格式与统计口径 |
| “这是我故意这么写的，为了评分松一些” | 移出问题清单，底稿记“教师评分尺度”，不写成错误 |
| “这里它读错了，原文不是这样” | 回到渲染图逐字核对；确认抽取错误就整条删除，并在底稿记录“文本抽取误报”，不要换个说法保留 |
| “这个确实难，但我要保留” | 从报告移到对话提醒，不占问题编号 |
| “分数确实不对” | 保留，补上具体学生、分项和总评，写成可复核的算式 |
| “这个我们一直都是这么做的” | 不直接删除；先核对学院现行标准，标准没有要求的，降为提醒 |
| “这题没错，答案不唯一” | 按 `paper-correctness.md` 复核是否属多解或约定差异；属实则整条删除，并在底稿记“多解误报” |

连续出现同类误报时，回头检查抽取方式和判定规则，而不是逐条向教师解释。**教师纠正一次，规则就应该长一截。**

## 措辞要求

- 没核准的疑点不写。确需提示时写“建议复核”，不写具体“错误数值”。
- 出题类问题按“条件—复算—矛盾”三段写，附关键中间量；不写“经核查有误”“显然不成立”。
- 已核准的写事实、位置、影响，不用“严重”“显然”“明显不当”等加重词。
- 不替教师解释动机，不写“教师疏忽”“态度不认真”。
- 一条问题只讲一件事，避免把排版、评分、数据混在同一句里。
