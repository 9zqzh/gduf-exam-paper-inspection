# 整改点认定：写进报告前的三道筛子

报告不是“材料勘误表”，而是教师对本次试卷工作的自查小结。写入第四部分的应当是**下一次命题或下一轮教学可以改进的方向**，不是这次归档材料里每一处可以立即修改的细节。

因此，动笔前先明确三条边界：

1. **不判断答案对错**。题目是否可解、答案数值是否正确、选项是否唯一、答案与试题知识范围是否对应，一律不核、不写。
2. **不要求改本次材料**。缺件、补签、替换答案、重出 PDF 等事项只做对话提醒，不进报告和登记表。
3. **只写通用方向**。每条能落到“下一次命题”“下一套 A/B 卷”“下一教学周期”，并有一句事实依据。

通用条目见 `issue-library.md`；下面是筛选和改写规则。

## 第一道：责任归属——谁能在下一轮改？

| 责任主体 | 典型事项 | 处理 |
| --- | --- | --- |
| 教师下一轮可改 | 题型分值结构、评分细则、情境化设问、过程性考核设计、教学训练重点 | 可列为整改点 |
| 学校系统 | 成绩单、班级分析表的数值与版式、课程级分析表模板 | 只做记录，不写 |
| 统一模板 | 平时成绩表“XX”占位列、权重栏、审核表打印份数栏 | 不写 |
| 纸质归档 | 手写签名、公章、日期、答题册实体、审核表复印件、装订排序 | 对话提醒，不写 |
| 本次材料内容 | 某题答案、某处标点、某个单元格数值 | 不写；需要时口头提醒 |

只有“下一轮可改”的事项，才可能进入报告第四部分和《试卷自查登记表》。

## 第二道：依据门槛——有没有可指回材料的事实？

每条整改点至少满足一项：

- **题型分值**：某类题目分值占比、主客观题结构、A/B 卷题型是否一致。
- **评分标准结构**：是否按题给出给分点、是否有梯度或档次说明（只看结构，不看对错）。
- **成绩统计**：平均分、及格率、优秀率、标准差、分数段、平时与期末差值。
- **班级对比**：平行班均值、及格率、优秀率的差异。
- **材料结构**：是否附大纲、双向细目表、复核说明（只记有无，不评价内容）。

依据写进 `核查底稿.md`，报告正文概括表述。**没有依据的条目不写**；不要用“据说”“普遍反映”“感觉”代替。

## 第三道：影响判断——不改会怎样？

| 影响 | 判定 |
| --- | --- |
| 影响下一轮命题质量、评分尺度统一、过程性考核公平、课程目标达成分析 | 可写整改点 |
| 只影响本次材料观感、个别标点、单个数值 | 对话提醒 |
| 教师有意为之且有合理解释 | 不写 |

注意：**“影响本次归档”不等于“要写进报告”**。缺一份表、少一个签名，教师当下补上即可，属于事务性提醒；报告写的是下一轮怎么做得更好。

## 整改点准入（四条同时满足）

1. **下一轮可改**：通过调整命题、评分细则、考核设计或教学安排就能改进。
2. **有依据**：能在底稿指回题型分值、评分标准结构、成绩数据或班级对比。
3. **写得通用**：不点具体题号、不写答案数值、不下“错误”结论。
4. **有对应措施**：第五部分能写清“做什么、何时完成、谁复核”。

四条缺一条，就不要写。

## 默认不列清单

| 类别 | 例子 | 处理 |
| --- | --- | --- |
| 答案对错 | 答案算错、题目无解、选项不唯一、答案与试题不匹配 | 不核、不写；教师问起只建议自行复核 |
| 本次材料缺件 | 课程级分析表、答题册、审核表未提供 | 报告写“未提供、未能核验”，对话提醒 |
| 签字盖章日期 | 电子稿无手写签名、公章、日期 | 对话提醒纸质归档补齐 |
| 系统导出表 | 班级分析表均值、标准差、及格率口径；课程级分析表格式 | 底稿注明“系统导出”，不写 |
| 统一模板字段 | 平时成绩表“XX”列、权重栏、审核表打印份数 | 不写 |
| 学校统一印制卷面 | 专业班级、考试日期、答题要求栏 | 不写 |
| 个别排版细节 | LaTeX 残留、重复标点、多余字符、单元格错位 | 对话提醒，不写 |
| 表内算术 | 分数÷满分≠百分比、两班数值雷同 | 对话提醒核对，不写 |
| 单题难度体感 | 计算量大、某题偏难 | 可转为 P6“难度与学情匹配”，不点题号 |
| 教师评分尺度 | “只写1也算对”“酌情给分” | 不写 |

## 旧写法怎么改成新写法

| 旧写法（硬伤式） | 新写法（通用式） |
| --- | --- |
| B 卷答案与试题不匹配，第1题无解，A卷填空3答案写成转置 | 主观题评分细则还可进一步细化，梯度给分不够明确（P1） |
| A 卷评分标准只有前两题有步骤分，其余 50 分没有给分点 | 同上，不写具体分值 |
| 课程级分析表缺失、答题册 96 份未提供、签字盖章空白 | 不写；报告只写“未提供、本项未能核验”，交付时提醒 |
| 两班分析表证明题 11.43÷20 写成 55.2% | 不写；对话提醒核对表内算术 |
| B 卷第7题 SVD 矩阵无有理根，两卷难度不对等 | 试卷难度与学情匹配还可优化，A/B 卷难度梯度可进一步平衡（P6） |
| 全卷无情境化、开放性题目，创新性 0 分 | 试题创新性还可进一步提升，情境化、开放性题目较少（P2） |

## 教师反驳时怎么处理

| 教师说法 | 处理 |
| --- | --- |
| “这个答案没错/题目有多解” | 本来就不核答案对错；不讨论，整条不写 |
| “这是学校系统导出的，改不了” | 不写；底稿注明“系统导出” |
| “材料我马上补” | 不写进报告；交付时确认是否已补，报告只写“未提供、未能核验” |
| “这条太笼统，能不能写具体点” | 可以补一句依据（题型分值或成绩数据），但仍不点题号、不写答案数值 |
| “我们一直都是这么做的” | 先核对学院现行标准；标准没有要求的，不写或降为对话提醒 |
| “这条不适用我们课程” | 直接删除，换用 `issue-library.md` 中更贴合的条目；不硬凑条数 |

连续出现同类争议时，回头检查条目选择是否过于具体，而不是逐条解释。

## 措辞要求

- 用“还可进一步”“有待完善”“可适当”“建议”；不用“错误”“不符”“严重”“必须立即”“明显不当”。
- 一条只讲一件事，不把评分、成绩、材料混在一句里。
- 不替教师解释动机，不写“教师疏忽”“态度不认真”。
- 不写“经核查发现……错误”，改写为“从题型结构/成绩数据看，……还可进一步……”。
- 报告正文不出现具体学生姓名、学号、单题答案和复算过程。
