# 通用整改点库

报告第四部分和《试卷自查登记表》只写**通用、可对下一次命题或下一轮教学提出的改进方向**。本文件提供标准条目和写法，避免每次都去逐题挑错，也避免把报告写成“材料勘误表”。

## 一、使用原则

1. **不判答案对错**。不验算题目、不比对答案数值、不判断选项唯一性、不核对答案与试题的知识范围。答案内容不在核查范围。
2. **不改本次材料**。整改措施落在下一套 A/B 卷、下一轮教学或下一轮成绩分析；不写“补做、补签、替换、重出 PDF”这类要求。
3. **3—5 条即可**。按课程实际挑选，不硬套；同类问题合并，不拆条凑数。
4. **每条一句依据**。依据来自题型分值、评分标准结构、成绩统计或班级对比，写在核查底稿；报告正文概括表述，不展开题号和数值细节。
5. **措辞留有余地**。用“还可进一步”“有待完善”“可适当增加”，不用“错误”“不符”“严重不足”“必须立即”。

## 二、标准条目

### P1 主观题评分细则细化

**适用**：评分标准以参考答案为主，综合题、设计题、论述题缺少步骤分或档次说明。

**报告写法**：

> 主观题评分细则还可进一步细化。综合计算、证明或方案设计类题目以参考答案和要点给分为主，部分正确情形的梯度给分不够明确，不同阅卷人对同一份答卷的尺度可能存在差异。

**整改写法**：

> 下一次命题时完善主观题评分细则，按关键步骤设置梯度分值，明确“部分正确”情形的给分规则，由教研室复核后随试卷归档。整改时限：下一套 A/B 卷命题完成前。

### P2 试题创新性提升

**适用**：全卷以封闭性、标准答案题为主，没有情境化、开放性、探究性题目。

**报告写法**：

> 试题创新性还可进一步提升。试卷以教材知识点和常规题型为主，情境化、开放性题目较少，学生结合行业实际分析问题、表达不同思路的空间有限。

**整改写法**：

> 下一套试卷在保持基础题比例的前提下，适度增加情境化、开放性设问，可设置条件讨论、方案比较、方法选择类小问。整改时限：下一套 A/B 卷。

### P3 高阶题或综合应用题权重

**适用**：客观题、识记类分值偏高，综合应用、分析设计类分值偏低。

**报告写法**：

> 试卷题型结构还可进一步优化。客观题和基础识记类题目分值占比较高，综合应用类题目分值相对有限，对学生分析、设计和迁移能力的区分还可加强。

**整改写法**：

> 下一次命题优化题型和分值结构，适当提高综合应用类题目比重，保持基础题、综合题、提高题的合理梯度。整改时限：下一套 A/B 卷。

### P4 过程性考核区分度

**适用**：平时成绩明显高于卷面成绩，或平时成绩优秀率偏高、分布集中。

**报告写法**：

> 过程性考核的区分和诊断作用还可进一步发挥。平时成绩整体偏高、分布较集中，与期末卷面成绩差距较大，部分学生的平时表现差异未能在成绩中充分体现。

**整改写法**：

> 下一轮教学明确过程性考核各环节的评分依据和权重，适当增加作业、测验、课堂表现等过程性成果的区分度，使平时成绩更能反映学习过程。整改时限：下一教学周期持续执行。

### P5 平行班成绩差异

**适用**：同一课程多个平行班，卷面均值、及格率或优秀率存在可见差异。

**报告写法**：

> 平行班之间成绩存在一定差异。各班卷面平均分、及格率不完全一致，反映教学进度、训练重点或学情基础存在差别，后续可加强班际教学协同。

**整改写法**：

> 加强集体备课和薄弱环节专项训练，统一教学进度与重点，针对差异较大的班级增加答疑和练习。整改时限：下一教学周期持续执行。

### P6 难度与学情匹配

**适用**：卷面平均分偏低、不及格率偏高，或优秀率过高、区分度不足。

**报告写法**：

> 试卷难度与当前学情的匹配还可优化。卷面成绩整体偏难（或偏易），基础题、综合题、提高题的比例可结合近两届成绩分布进一步调整。

**整改写法**：

> 下一次命题结合本届成绩分布调整难度梯度，适当增减基础题或提高题比例，命制后由教研室做难度预估。整改时限：下一套 A/B 卷。

### P7 试卷分析针对性

**适用**：教师自填的班级/课程成绩分析表内容较概括（系统导出表不适用）。

**报告写法**：

> 试卷分析的针对性还可加强。现有分析对失分原因和改进措施的归纳比较概括，对具体题型、知识模块和班级差异的分析还可进一步细化。

**整改写法**：

> 下一轮成绩分析时结合逐题得分或题型得分，说明主要失分点和改进措施，避免只写总体评价。整改时限：下一学期成绩分析时。

### P8 课程目标与试题对应说明

**适用**：成绩分析或课程总结中，试题与课程目标的对应关系说明较概括，达成情况分析缺少题目层面的支撑。

**报告写法**：

> 试题与课程目标的对应说明还可进一步补充。各题对应的课程目标和知识模块说明不够清晰，课程目标达成分析还可更多结合题型得分展开。

**整改写法**：

> 下一次命题前完善双向细目表，标注题号、分值、知识模块和课程目标对应关系，随试卷一并归档。整改时限：下一套 A/B 卷命题前。

## 三、按课程类型挑选

| 课程类型 | 优先条目 |
| --- | --- |
| 笔试类必修课 | P1、P2、P3、P4、P5、P6 |
| 机考/考查类 | P1、P2、P4、P7 |
| 实验（实践）课 | P1、P2、P4、P7 |
| 课程论文 | P1、P2、P7、P8 |
| 单班授课 | 不选 P5 |

一次选 3—5 条。数据上没有依据的条目不选；选了就要在底稿写清依据。

## 四、依据怎么写（底稿）

每条整改点在 `核查底稿.md` 留一行，写“条目编号 + 观察到的事实 + 数据/材料位置”：

| 条目 | 观察到的事实 | 依据位置 |
| --- | --- | --- |
| P1 | 评分标准仅前两题标注步骤分，其余主观题只有解答 | A卷答案第2—4页 |
| P2 | 两套卷均为计算、证明题，无情境化、开放性设问 | A/B卷题型结构 |
| P4 | 平时均分81.47，期末均分58.17，差23.30分 | 成绩单统计 |
| P5 | 两班期末均分差2.70分，及格率差1.04个百分点 | 成绩单分班统计 |

报告正文只写概括结论，不复制整张表。

## 五、禁止写法

- “B卷答案算错/与试题不匹配/第1题无解。”——属于答案对错判断，不写。
- “A卷填空题第3题答案写成转置，应改为……”——不写具体题目和更正值。
- “11月2日前补做课程级分析表、补齐答题册、补签盖章。”——要求改材料，不写。
- “证明题平均11.43分写成55.2%，应为57.2%。”——表内算术问题，改为对话提醒，不写。
- “试卷难度明显不当，必须重出。”——结论过重，改成“难度与学情匹配还可优化”。
- 五条以上、每条都带题号和数值——过于具体，违背本库的写法。

## 六、与第四、五部分的对应

- 第四部分：每条一段，第一句写方向，第二句写依据，第三句写影响或风险，控制在 80—150 字。
- 第五部分：与第四部分同编号、同顺序，写“做什么 + 何时完成 + 谁复核”，一句到两句。
- 《试卷自查登记表》：问题描述取第四部分首句和依据，备注写整改时限；不写学生姓名和具体分数。
