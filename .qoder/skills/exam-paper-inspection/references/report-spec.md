# 《教师试卷检查结果报告》写作规范

## 一、硬性要求

- 全文不少于 **1000 字**（按 Word 字数统计口径：汉字 + 英文/数字词）。
- 必须包含五个模块，标题与学院模板一致。
- 报告由任课教师署名，日期手写或填写。
- 所有数据必须可追溯：来自成绩单、分析表、试题、归档清单或教师明确确认。
- 不得编造比例、人数、分数、归档编号；无法核验的，写明“材料未提供，本项未能核验”。
- **第四部分只写通用整改点**：3—5 条，面向下一次命题或下一轮教学，有题型分值、评分标准结构或成绩数据作依据。答案对错、材料缺件、系统导出表及其统计口径、统一模板字段、纸质归档签章、教师评分尺度，不写进报告（判定见 `issue-triage.md`，条目见 `issue-library.md`）。
- **不判断答案对错**：不验算题目、不比对答案数值、不判断选项唯一性、不核对答案与试题的知识范围。报告不出现“答案有误”“题目无解”“算错”等结论。
- **“两性一度”不写百分比**：正文用题号、分值、题干要求说明，逐题归类与占比留在核查底稿。

## 二、五个模块写什么

### 一、课程与试卷基本情况

- 课程性质、学时学分（有则写）、课程目标与考核要求。
- 学年学期、授课班级、选课人数、考核方式、过程性考核占比。
- 试卷命题与审核过程：谁命题、A/B 卷、是否经教研室审核、使用哪套卷考试。
- 试卷套数：A/B 卷、补考缓考卷。

### 二、命题规范与“两性一度”自查情况

分四小节写：

- **（一）命题规范自查**：A/B 卷结构、题量与分值、卷面要素、参考答案与评分标准是否齐全并按题给分；只写能核验的形式，不判断答案内容对错。与大纲的符合度只写能核验的部分。学校统一印制的专业班级、考试日期、答题要求栏不写。
- **（二）高阶性自查**：用“高阶题共×分，主要是第×题（×分）要求……”的方式写，指出题目考查的分析、综合或设计能力；不写占比。逐题认知层次表放核查底稿。
- **（三）创新性自查**：情境化题目、开放性/探究性题目、学科前沿内容，用题号举例；没有就如实写“以常规计算与证明为主，情境化、开放性题目较少”，不用百分比。
- **（四）挑战度自查**：难度梯度、提高题、区分度，结合分数段与标准差给总体判断；不写“提高题占×%”。

写法与计算口径见 `two-natures-one-degree.md`。每一条结论后面要有题号或数据支撑。**百分比只在核查底稿出现**，正文用分值和题例说话。

### 三、成绩统计分析

- **（一）最终成绩**：平均分、及格率、优秀率、不及格率、标准差、分数段分布；结合命题判断是否符合“两性一度”。
- **（二）平时成绩**：构成（考勤/作业/测验/课堂表现等）、分布、过程性材料留存情况。
- **（三）试卷成绩**：平均分、及格率、标准差；结合试题结构分析难度与区分度。

必须说明数据来源（教务系统成绩单/成绩登记表），并保持三个口径前后一致。缺失记录（缺考、缓考、作弊等）要单列说明，缺考不计入平均分与及格率分母。

- **班级成绩分析表**：数据以系统导出为准，不评价其均值、标准差、及格率口径；发现表内算术明显不符（如分数÷满分≠所列百分比）或两班数值完全雷同时，在交付对话中提醒核对，不写进第四部分。
- **平时成绩**：只写构成、分布与留存情况；总评与分项对不上时，在交付对话中请教师核对取数，报告不逐人列示，也不要求补模板里没有的权重栏。
- **异常阈值**：按实考人数口径计算；若按选课人数（含缺考 0 分）会跨过阈值，报告注明两种口径的结果，不判定哪种口径正确，由学院认定。

若不及格率或优秀率达到异常阈值，按 `standards.md` 第五节写明后续处理。

### 四、发现的问题与不足

写 3—5 条通用整改点，按 `issue-library.md` 挑选。每条合成一段，80—150 字，包含三部分：

1. 改进方向（一句话）。
2. 事实依据（题型分值、评分标准结构、成绩数据或班级对比，概括写，不点具体题号答案）。
3. 影响或风险（一句话，不夸张）。

示例（可直接照此写）：

> 1. 主观题评分细则还可进一步细化。综合计算、证明类题目以参考答案和要点给分为主，部分正确情形的梯度给分不够明确，不同阅卷人对同一份答卷的尺度可能存在差异。

> 2. 试题创新性还可进一步提升。两套卷以常规计算与证明为主，情境化、开放性题目较少，学生结合实际问题分析、表达不同思路的空间有限。

> 3. 过程性考核的区分和诊断作用还可进一步发挥。平时成绩平均81.47分，期末卷面平均58.17分，两者差距较大；平时成绩优秀率31.25%，期末优秀率4.17%，过程性考核对学习过程的区分还可加强。

以下事项**不要**写进第四部分，交付时用对话提醒即可：

- 答案与试题是否对应、答案数值是否正确、选项是否唯一、题目是否可解（不在核查范围）。
- 材料缺件（课程级分析表、答题册等）、签字盖章日期空白、审核表打印份数（事务性提醒）。
- 表内算术错误、跨班数值雷同（提示核对）。
- 个别排版细节（LaTeX 残留、重复标点、多余字符）。
- 学校系统导出表的口径与版式、统一模板字段、学校统一印制卷面栏。
- 教师评分尺度、“只写1也算对”等表述。
- 某题计算量大、A/B 两卷难度体感差异（可并入 P6“难度与学情匹配”，不点题号）。

整改点必须来自实际核查，不能为了“看起来认真”而编造或凑条数。**三条有依据的通用方向，胜于十条材料勘误。**

### 五、整改措施与工作建议

- 与第四部分同编号、同顺序，一条对应一条。
- 每条写清“做什么 + 何时完成 + 谁复核”，时限落在下一套 A/B 卷、下一教学周期或下一学期成绩分析。
- 不写补做、补签、替换、重出 PDF 等要求；确实需要补的材料，在交付对话中提醒。
- 可对学院命题管理、课程建设提建议，但不空泛表态。结尾可加一句“以上事项纳入下一轮课程建设，不涉及本次归档材料的改动”。

## 三、写作风格

- 客观、平实、克制；方向概括、依据可查。
- 不用“高度重视、深刻认识、切实提高”等空话堆字数。
- 不写“本报告由AI生成”等与报告无关的内容。
- 不写具体题号答案、复算过程、单题更正值；不写“经核查答案有误”。
- 结论用“符合 / 基本符合 / 有待改进”，并给证据。
- 报告中课程名称、教师姓名、班级、人数必须与知识库/成绩单一致。

## 四、生成报告的数据文件

先写 `report_payload.json`，再调用 `build_report_docx.py`。字段：

```json
{
  "teacher": "高平安",
  "department": "计算机与科学系",
  "course_name": "Java程序设计",
  "course_type": "必修课",
  "term": "2025-2026-2学期",
  "assessment": "闭卷笔试；过程性考核占比30%",
  "classes": "25清远计算机科学与技术-1～3班，共167人",
  "paper_sets": "A/B卷各1套",
  "subtitle": "（2025—2026学年试卷专项检查）",
  "sections": [
    {"heading": "一、课程与试卷基本情况", "paras": ["……"]},
    {"heading": "三、成绩统计分析", "paras": ["……"],
     "table": {"headers": ["统计口径", "平均分", "及格率", "优秀率", "不及格率", "标准差"],
               "rows": [["最终成绩", "76.8", "91.6%", "17.5%", "8.4%", "10.2"]]}}
  ],
  "sign_date": "2026年11月3日"
}
```

`course_type` 只能取：必修课、选修课、课程论文、实验（实践）课。

## 五、配套《试卷自查登记表》

字段：开课学年、课程名称、课程类型、专业班级、任课/老师、涉及学生姓名或学号、问题点及描述、备注。

- **只放通用整改点**，与报告第四部分一一对应；对话提醒、答案对错、材料缺件、系统口径、模板字段、纸质签章不写入。
- 每个整改点一行；同一方向涉及多个班级可合并写。
- “涉及学生姓名或学号”通常留空；只有确实指向具体学生时才填，优先写学号。
- 问题描述与报告第四部分保持一致，可更简短；备注写整改时限。
- 用 `build_selfcheck_xlsx.py` 生成，输出为横向、单页宽。

## 六、常见错误

- 字数不足：五部分平均分配，每部分约200字；靠事实细节而不是套话扩写。
- 数据前后矛盾：最终成绩、平时成绩、试卷成绩的人数与均值对不上。
- 把“试卷成绩”与“最终成绩”混为一谈。
- 只写优点不写问题，或问题没有位置与证据。
- 归档编号张冠李戴，或把合班/单班记录重复计算。
- 系统导出的课程级分析表评字数、评格式；或非试卷类自填分析表内容空泛却写“分析具体”。
- 没看纸质原件就写“签字盖章齐全”。
- 把学校系统导出的统计口径、统一模板字段、纸质签章写成问题。
- 把“题目偏难”“计算量大”这类难度体感写成硬伤；应改为 P6 通用方向。
- 第四部分写成材料勘误表：答案错误、补件、补签、表内算术、个别标点，均超出本次报告范围。
- 整改措施要求本次修改材料，教师无法在提交前完成。
- 通用条目没有依据，变成空话；每条至少有一项题型分值、评分标准结构或成绩数据支撑。
- 报告正文写“识记20%、高阶35%”，教师无法核对算法；占比应留在底稿。
