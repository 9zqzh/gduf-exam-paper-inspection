# 《教师试卷检查结果报告》写作规范

## 一、硬性要求

- 全文不少于 **1000 字**（按 Word 字数统计口径：汉字 + 英文/数字词）。
- 必须包含五个模块，标题与学院模板一致。
- 报告由任课教师署名，日期手写或填写。
- 所有数据必须可追溯：来自成绩单、分析表、试题、归档清单或教师明确确认。
- 不得编造比例、人数、分数、归档编号；无法核验的，写明“材料未提供，本项未能核验”。
- **第四部分只写硬性问题**：教师可控、位置明确、证据可复核、影响清楚。学校系统导出表及其统计口径、统一模板字段、纸质归档签章与答题册、教师有意的评分尺度、单题难度体感，不写进报告（判定见 `issue-triage.md`）。
- **“两性一度”不写百分比**：正文用题号、分值、题干要求说明，逐题归类与占比留在核查底稿。

## 二、五个模块写什么

### 一、课程与试卷基本情况

- 课程性质、学时学分（有则写）、课程目标与考核要求。
- 学年学期、授课班级、选课人数、考核方式、过程性考核占比。
- 试卷命题与审核过程：谁命题、A/B 卷、是否经教研室审核、使用哪套卷考试。
- 试卷套数：A/B 卷、补考缓考卷。

### 二、命题规范与“两性一度”自查情况

分四小节写：

- **（一）命题规范自查**：A/B 卷结构、题干与答案、题量与分值、参考答案与评分标准；与大纲的符合度只写能核验的部分。学校统一印制的专业班级、考试日期、答题要求栏不写。
- **（二）高阶性自查**：用“高阶题共×分，主要是第×题（×分）要求……”的方式写，指出题目考查的分析、综合或设计能力；不写占比。逐题认知层次表放核查底稿。
- **（三）创新性自查**：情境化题目、开放性/探究性题目、学科前沿内容，用题号举例；没有就如实写“以常规计算与证明为主，情境化、开放性题目较少”，不用百分比。
- **（四）挑战度自查**：难度梯度、提高题、区分度，结合分数段与标准差给总体判断；不写“提高题占×%”。

写法与计算口径见 `two-natures-one-degree.md`。每一条结论后面要有题号或数据支撑。**百分比只在核查底稿出现**，正文用分值和题例说话。

### 三、成绩统计分析

- **（一）最终成绩**：平均分、及格率、优秀率、不及格率、标准差、分数段分布；结合命题判断是否符合“两性一度”。
- **（二）平时成绩**：构成（考勤/作业/测验/课堂表现等）、分布、过程性材料留存情况。
- **（三）试卷成绩**：平均分、及格率、标准差；结合试题结构分析难度与区分度。

必须说明数据来源（教务系统成绩单/成绩登记表），并保持三个口径前后一致。缺失记录（缺考、缓考、作弊等）要单列说明，缺考不计入平均分与及格率分母。

- **班级成绩分析表**：数据以系统导出为准，不评价其均值、标准差、及格率口径；只在表内算术明显不符（如分数÷满分≠所列百分比）或两班数值完全雷同时提示核对。
- **平时成绩**：只写构成、分布与留存情况；总评与分项对不上时，点名具体学生和数值，请教师核对取数，不要求补模板里没有的权重栏。
- **异常阈值**：按实考人数口径计算；若按选课人数（含缺考 0 分）会跨过阈值，报告注明两种口径的结果，不判定哪种口径正确，由学院认定。

若不及格率或优秀率达到异常阈值，按 `standards.md` 第五节写明后续处理。

### 四、发现的问题与不足

只写通过 `issue-triage.md` 三道筛子的硬性问题：教师可控、位置明确、证据可复核、影响清楚。每条包含：

1. 问题所在位置（哪份材料、哪道题、哪个单元格或学号）。
2. 事实描述（原文、数值、算式，能复核）。**出题与答案类问题按“条件—复算—矛盾”三段写**：先写题目所给数据，再写关键中间量（特征值、秩、内积、合计分值、执行结果），最后写与题目要求的冲突；不写“经核查有误”。
3. 影响或风险（一句话，不夸张）。

示例：

> 1. B卷《标准答案及评分标准》的正文为行列式、克拉默法则、二次型等内容，与B卷试题的线性空间、线性变换、特征值、奇异值分解不对应；同目录参考答案只有结果、没有分步给分点，按现有答案无法复核评分。

> 2. 2班《班级成绩分析表》记证明题平均11.43分、满分20分，表中写作55.2%，按11.43÷20应为57.2%；该数值与1班完全相同，需核对是否套用了1班数据。

以下事项**不要**写进第四部分，交付时用对话提醒即可：

- 课程级《课程试卷及成绩分析表》未随电子材料提供、格式只有两段（学校系统导出）。
- 答题册未随电子材料提供、份数与实到人数不一致（纸质归档环节）。
- 成绩单、分析表、审核表的手写签字、公章、日期空白（电子稿本来就没有）。
- 班级分析表均值、标准差、及格率、优秀率的口径（系统导出，不质疑）。
- 平时成绩表“XX”列、权重栏、审核表打印份数（统一模板字段）。
- 卷面未印专业班级、考试日期、答题要求（学校统一印制栏）。
- “只写1也算对”等评分放宽表述（教师评分尺度）。
- 某题计算量大、A/B两卷难度体感差异（命题建议，不是硬伤）。

问题必须来自实际核查，不能为了“看起来认真”而编造或凑条数。**三条扎实的硬伤，胜于十条系统性提醒。**

### 五、整改措施与工作建议

- 逐条对应第四部分的硬性问题，写明具体动作与完成时限。
- 措施要可执行：改什么题、补什么材料、何时完成、由谁复核。
- 系统、模板、纸质签章类提醒不写整改措施；需要时可写“纸质归档时按学院要求补齐签章”这类流程说明，但不要对应成问题编号。
- 可对学院命题管理、课程建设提建议，但不要空泛表态。

## 三、写作风格

- 客观、具体、克制；用事实和数据说话。
- 不用“高度重视、深刻认识、切实提高”等空话堆字数。
- 不写“本报告由AI生成”等与报告无关的内容。
- 结论用“符合 / 基本符合 / 有待改进”，并给证据。
- 报告中课程名称、教师姓名、班级、人数必须与知识库/成绩单一致。

## 四、生成报告的数据文件

先写 `report_payload.json`，再调用 `build_report_docx.py`。字段：

```json
{
  "teacher": "高平安",
  "department": "计算机与科学系",
  "course_name": "Java程序设计",
  "course_type": "必修课",
  "term": "2025-2026-2学期",
  "assessment": "闭卷笔试；过程性考核占比30%",
  "classes": "25清远计算机科学与技术-1～3班，共167人",
  "paper_sets": "A/B卷各1套",
  "subtitle": "（2025—2026学年试卷专项检查）",
  "sections": [
    {"heading": "一、课程与试卷基本情况", "paras": ["……"]},
    {"heading": "三、成绩统计分析", "paras": ["……"],
     "table": {"headers": ["统计口径", "平均分", "及格率", "优秀率", "不及格率", "标准差"],
               "rows": [["最终成绩", "76.8", "91.6%", "17.5%", "8.4%", "10.2"]]}}
  ],
  "sign_date": "2026年11月3日"
}
```

`course_type` 只能取：必修课、选修课、课程论文、实验（实践）课。

## 五、配套《试卷自查登记表》

字段：开课学年、课程名称、课程类型、专业班级、任课/老师、涉及学生姓名或学号、问题点及描述、备注。

- **只放硬性问题**，与报告第四部分一一对应；对话提醒、系统口径、模板字段、纸质签章不写入。
- 每个问题一行；同一问题涉及多个班级可合并写。
- “涉及学生姓名或学号”仅在能定位到具体学生时填写，否则留空；优先写学号。
- 问题描述与报告第四部分保持一致，可更简短。
- 用 `build_selfcheck_xlsx.py` 生成，输出为横向、单页宽。

## 六、常见错误

- 字数不足：五部分平均分配，每部分约200字；靠事实细节而不是套话扩写。
- 数据前后矛盾：最终成绩、平时成绩、试卷成绩的人数与均值对不上。
- 把“试卷成绩”与“最终成绩”混为一谈。
- 只写优点不写问题，或问题没有位置与证据。
- 归档编号张冠李戴，或把合班/单班记录重复计算。
- 系统导出的课程级分析表评字数、评格式；或非试卷类自填分析表内容空泛却写“分析具体”。
- 没看纸质原件就写“签字盖章齐全”。
- 把学校系统导出的统计口径、统一模板字段、纸质签章写成问题。
- 把“题目偏难”“计算量大”这类难度体感写成硬伤。
- 公式、矩阵、复选框没看渲染图就断言错误。
- 出题错误只写结论不写复算过程，或只算一遍就下结论；多解、约定差异被当成错误（见 `paper-correctness.md`）。
- 报告正文写“识记20%、高阶35%”，教师无法核对算法；占比应留在底稿。
