# 命题与答案正确性复核规程（学科知识三重复核）

出题错误是整套检查里**最容易误报、代价也最高**的一类：一旦把“题目本身没错”写成错误，教师会连带否定报告里其它真实问题。所以这一类不走普通流程，执行比其它问题更严的证据标准——**同一结论至少两次独立复现，且回到原件逐字核对，才算确认**。

## 一、适用范围

按本规程复核的“出题与答案错误”：

| 类型 | 典型表现 |
| --- | --- |
| 题目无解 / 条件矛盾 | 所给矩阵不可对角化却要求写出 A=PΛP⁻¹；条件互相冲突 |
| 答案与试题不对应 | 答案属于另一门课、另一学期、另一套卷；题号错位 |
| 参考答案算错 | 特征值、秩、内积、概率、SQL 结果、程序输出与正确解不符 |
| 漏解 / 多解未说明 | 特征向量只给一个却说“全部”；方程只给一组解 |
| 选项设置错误 | 无正确项、两项等价、选项含题干未定义的符号 |
| 分值标注错误 | 小题分值之和≠大题分值；各大题之和≠100；标题分值与实际列题不符 |
| 评分标准缺给分点 | 只有结果、没有步骤分；给分点与答案步骤对不上 |
| 记号/条件缺失 | 题干用到未定义的符号、未说明数域或维度 |
| 超纲 | 需要教学大纲或教材章节作证据，否则只能提醒 |

**不属于出题错误**：难度、计算量、题型偏好、排版观感、学校统一印制栏。这些按 `issue-triage.md` 处理，不要混进这一类。

## 二、第一步：建立这门课的学科核查基线

复核前先明确“按什么标准判对错”，不能凭印象。

1. **确定学科口径**：课程名称、教材、教学大纲（有则用）、学时章节。知识库只能给课程属性，**学科判定标准必须来自该课程教材/大纲或学科通用定义**。
2. **列“考点—判定依据”清单**：每个要被判定的考点，写下定义、定理、充要条件和前提（数域、维度、定义域）。
3. 判定依据写进 `核查底稿.md`，复核时逐条对照，不临时改标准。

常见学科的判定要素示例（按实际课程替换）：

| 学科 | 判定要素举例 |
| --- | --- |
| 线性代数 | 可对角化 ⟺ 每个特征值的几何重数=代数重数（“有 n 个不同特征值”只是充分条件）；Schmidt 正交化第 k 步只减去在前 k−1 个向量上的投影；A=UΣVᵀ 中 U、V 的列分别是 AAᵀ、AᵀA 的单位特征向量，奇异值取非负平方根 |
| 概率统计 | 密度函数非负且积分为 1；分布函数右连续；独立⇒不相关，反之不成立；假设检验拒绝域方向与备择假设一致 |
| 程序设计 | 参考答案在题面给定输入、边界输入（空、极值、溢出）下能否得到题面要求的输出；时间/空间复杂度是否满足题面约束；输出格式（分隔符、精度）是否与题面一致 |
| 数据结构/算法 | 构造反例检验算法正确性；最坏/平均复杂度是否与题面要求相符 |
| 数据库 | SQL 能否在给定模式上执行；结果列、行序与题面要求一致；NULL、连接、分组语义是否正确 |
| 大学物理/电路 | 量纲、数量级、边界条件（开路/短路、t→∞）是否自洽 |

没有教材或大纲依据时，“超纲”只能作为对话提醒，不能写成错误。

## 三、第二步：独立重算（第一遍，先不看答案）

- 只拿试题，独立求解，记录**关键中间量**：行列式、特征多项式、特征值、秩、内积、概率、SQL 结果集、程序输出。
- 严禁先看答案再“找茬”——先看答案会让复核跟着答案的思路走，漏掉真正的错。
- 能符号计算就用工具复算，命令与结果记入底稿，例如：

```bash
python -c "import sympy as sp; A=sp.Matrix([[1,1,1],[0,1,1],[0,0,2]]); print(A.eigenvals()); print(A.is_diagonalizable())"
```

工具不可用时手算，并把每一步写进底稿（手算过程就是证据）。

## 四、第三步：换一条路径复算（第二遍）

必须用与第一遍**不同的方法或视角**，至少一条：

- **代入验证**：把答案代回原式（A=PΛP⁻¹、LU=A、UΣVᵀ=A、解代回方程、SQL 在样例数据上跑一遍）。
- **恒等式/不变量**：tr(A)=Σλ、det(A)=Πλ、rank 与零空间维数、概率总和为 1、能量/量纲守恒。
- **特殊值与边界**：取 n=2、λ=0、零向量、空输入、极大值，看结论是否仍成立。
- **几何/空间**：维数公式 dim(U+W)=dimU+dimW−dim(U∩W)；交集元素同时满足两组方程。
- **正交性**：逐对算内积、算模长；不成立时写出具体内积值（如 4/√18≠0）。
- **证明题**：逐步检查前提是否满足，主动构造反例试图推翻。
- **选择题**：逐项代入或构造反例，确认“唯一正确项”，并确认干扰项确实错误。

两次结论不一致时，不要挑一个写进报告——**回到原件重读条件，仍不一致就降级为“请教师复核”**。

## 五、第四步：回到原件逐字核对（第三遍）

- 把页面渲染成图片逐字读题干：矩阵每个元素、正负号、上下标、括号、题号、分值、单位。
- 文本抽取与渲染图不一致时，**以渲染图为准**；确认是抽取问题就整条删除，不换说法保留。
- 检查是否有勘误页、补充说明、口试说明，或同一题在不同页/不同卷有不同版本。
- 检查分值：先数小题，再算合计，再对标题和卷面总分，三者一致才算核清。

## 六、第五步：反方论证（主动推翻自己）

写下“这题可能是对的”最强理由，逐条排除：

| 可能 | 处理 |
| --- | --- |
| 题目允许多解 | 特征向量差非零常数倍、正交化顺序不同、SVD 的 U/V 列顺序与符号不同、基的排列不同——只要满足定义即为正确，不判错 |
| 学科约定不同 | Jordan 块顺序、Doolittle 的 L 是否单位下三角、特征向量归一化方式；按该课程教材口径判断，不按个人习惯 |
| 近似值 | 在题目要求的精度内（如保留两位小数）不算错；只有明显超出舍入范围才算 |
| 题面用词 | “求一个”与“求全部”、“是否可对角化”与“求对角化矩阵”要求不同，先看清问的是什么 |
| 印刷体误读 | λ 与 1、α 与 a、上标 −1 与下标、相似符号 ≠ 与 =，必须放大渲染图确认 |
| 教师有意简化 | 如限定实数域、限定 3 阶，先看题干有没有写明 |

排除不掉，就降级为“建议复核”，不写“错误”。

## 七、结论分级与出口

| 级别 | 成立条件 | 处理 |
| --- | --- | --- |
| **确认错误** | 两次独立方法结论一致 + 原件核对无误 + 反方论证已排除 | 可写进报告第四部分与登记表 |
| **存疑** | 方法间不一致、依赖约定、原件不清、缺大纲依据 | 只写“建议复核”，对话提醒；不写具体“错误数值” |
| **无误** | 复算通过 | 底稿记“已复算无误”，报告不写；防止下次重复怀疑 |

确认错误仍要通过 `issue-triage.md` 的三道筛子（教师可控、位置明确、影响清楚），证据门槛按本规程执行。

## 八、证据写法：条件—复算—矛盾

报告里每条出题错误必须能被人照着复算一遍，三段式：

1. **条件**：材料名 + 页码/题号 + 题目所给的具体数据。
2. **复算**：关键中间量（特征值、秩、内积、合计分值、执行结果）。
3. **矛盾**：与题目要求或答案的冲突点，一句话说清后果。

示例（可直接照此写）：

> B 卷计算题第 1 题所给矩阵 A 的三行分别为（1,1,1）、（0,1,1）、（0,0,2）。其特征多项式为 (λ−1)²(λ−2)；λ=1 时 A−I 的三行分别为（0,1,1）、（0,1,1）、（0,0,1），秩为 2，几何重数为 3−2=1，小于代数重数 2，故不存在可逆矩阵 P 使 A=PΛP⁻¹，第(3)问无解。

反例（**禁止**这样写）：

- “经核查，B 卷答案存在错误。”——没有条件、没有复算，教师无法核对。
- “该题显然不可对角化。”——结论没有中间量。
- “答案与试题不符。”——没说是哪几题、差在哪。

## 九、底稿留痕：题目正确性复核表

每道被质疑的题留一行，结论为“无误”的也要留（避免下次重复怀疑）：

| 题号 | 考点/判定依据 | 独立重算结果 | 第二路径 | 原件核对 | 反方论证 | 结论 | 证据位置 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| B 计算 1 | 可对角化充要条件 | λ=1(二重)、2；rank(A−I)=2，几何重数 1 | 代入 A=PΛP⁻¹ 无解；sympy `is_diagonalizable()=False` | B 卷第 2 页矩阵元素逐字核对一致 | 题目未限定复数域，结论不变 | 确认错误 | B 卷第 2 页、答案第 2 页 |

## 十、高频误报陷阱（已踩过，逐条防）

1. **抽取错位**：多行矩阵被合并成一行、上下标丢失、选项跨页断开。必看渲染图。
2. **把多解判成错**：特征向量差常数倍、正交化顺序不同，只要满足定义就对。
3. **把等价记号判成错**：Aᵀ 与 A^T、α/β 顺序互换、行列式转置不变。
4. **题号孤立**：如“3.”落在页脚，先确认是排版断行，不是缺题。
5. **证明题分值**：标题写“2 小题 20 分”，正文却列 3 题 12+10+8——先数小题再算合计，别只看标题。
6. **答案只有结果**：这属于“评分标准缺给分点”，单列一条，不要写成“答案算错”。
7. **把难度当错误**：计算量大、需要数值方法，是命题建议，不是出题错误。
8. **拿不准还硬写**：宁可写“建议复核”，也不写“经核查有误”。

## 十一、全卷快筛 + 疑点深核

时间有限时按这个顺序做，不要跳过任何一步：

1. **全卷快筛**（每题 1—2 分钟）：题目是否可解、答案是否对应、选项是否唯一、分值是否合计正确、记号是否都有定义。
2. **疑点标记**：把快筛中“像有问题”的题标出来，只对标记题做第二至六步的三轮深核。
3. **复核结论回填**：确认错误、存疑、无误三类分别落到报告、对话提醒、底稿。

全卷快筛发现但未深核的疑点，一律按“存疑”处理，不写进报告。
